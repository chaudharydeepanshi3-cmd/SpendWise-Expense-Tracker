SpendWise – Expense Tracker

SpendWise is a simple expense tracker built using HTML, CSS, and JavaScript. It helps users manage their income and expenses in one place.

Features

- Add income and expense transactions
- View total income, total expenses, and balance
- View transaction history
- Delete transactions
- Save transaction data in the browser using localStorage
- Display amounts in Indian Rupees (₹)

Technologies Used

- HTML5
- CSS3
- JavaScript

How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your web browser.

You can also open the project using Visual Studio Code and the Live Server extension.

Data Storage

Transaction data is saved in the browser's localStorage. Data is stored locally in that browser and is not automatically synced across devices.
